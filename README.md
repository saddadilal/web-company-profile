# Kampung Inggris – Company Profile

Website company profile sederhana (HTML + CSS) untuk kursus Bahasa Inggris.

## Struktur
```
index.html
style.css
images/
```

## Menjalankan
Buka `index.html` di browser.

## Deploy ke GitHub Pages
1. Push semua file ke repository GitHub (branch `main`).
2. Buka **Settings → Pages**.
3. Pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu Save.
4. Situs akan tersedia di `https://USERNAME.github.io/NAMA-REPO/`.
